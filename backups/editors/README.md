# Editor snapshots / Respaldos de editores

These are reference-only snapshots taken on 2026-10-05. The installer NEVER reads or applies them and NEVER installs extensions. Use your cloud sync normally.

Son respaldos de referencia del 2026-10-05. El instalador NUNCA los aplica ni instala extensiones. Puedes continuar usando la sincronización de nube.

Only reviewed appearance/editing preferences and shortcut keys/commands are included. Accounts, tokens, providers, command arguments, workspaces and extension state are excluded. This is a sanitized preference backup, not a complete editor data backup.

Solo se incluyen preferencias revisadas de apariencia/edición y atajos. Se excluyen cuentas, tokens, proveedores, argumentos de comandos, espacios de trabajo y estado de extensiones. Es un respaldo depurado de preferencias, no de todos los datos del editor.
